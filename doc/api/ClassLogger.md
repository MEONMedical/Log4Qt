# ClassLogger

## Class Overview

`ClassLogger` is a small helper that lazily resolves and caches a `Logger` named after a given `QObject`-derived class. It exists to back the `LOG4QT_DECLARE_QCLASS_LOGGER` macro: a class that uses the macro gains a private `ClassLogger` member and a public `logger()` accessor, and the first call to `logger()` resolves a `Logger` whose name is the runtime class name (from the object's `QMetaObject`). The resolved pointer is cached so subsequent calls are cheap.

## Project Structure and Dependencies

- Header: `src/log4qt/helpers/classlogger.h`
- Source: `src/log4qt/helpers/classlogger.cpp`
- Part of the `log4qt` library target (see `src/log4qt/CMakeLists.txt`, `log4qt_HEADERS_helpers`).

Dependencies:

- `log4qt/log4qtshared.h` — `LOG4QT_EXPORT` visibility macro.
- `<atomic>` — `std::atomic<Logger *>` for the cached pointer.
- `QObject` (forward declared in the header; the meta-object is used in the cpp) — supplies the class name via `metaObject()->className()`.
- `logmanager.h` (cpp only) — `LogManager::logger(const QString &)` performs the actual lookup.

## Class Hierarchy and Role

`ClassLogger` is a standalone class with no base class. It is not a `QObject` and is not part of any inheritance hierarchy. Its role is purely a per-class cache holder, instantiated once per object that carries the `LOG4QT_DECLARE_QCLASS_LOGGER` macro.

## Public Methods

#### ClassLogger()

Constructs the helper with an empty (null) cached logger pointer.

#### Logger *logger(const QObject *object)

Returns a pointer to the `Logger` named after the class of `object`.

On the first invocation the logger is obtained via `LogManager::logger(...)`, using `object->metaObject()->className()` (converted from Latin-1) as the logger name; the resulting pointer is cached. Subsequent invocations return the cached pointer without re-resolving.

`object` must not be null — this is enforced by `Q_ASSERT_X` in debug builds. Ownership of the returned `Logger` remains with the logger repository; the caller does not own it.

## Ownership and Lifecycle

A `ClassLogger` instance is owned by the host object (typically declared as a `mutable Log4Qt::ClassLogger` member by the `LOG4QT_DECLARE_QCLASS_LOGGER` macro) and shares the host's lifetime. The cached `Logger *` is **not owned** by `ClassLogger`; it points to a `Logger` managed by the global logger repository through `LogManager`, which outlives normal application objects. No cleanup is performed in the (defaulted) lifetime of the cache pointer.

## Thread Safety

All functions are thread-safe. The cached pointer is held in a `std::atomic<Logger *>` and resolved with a lock-free compare-and-exchange:

- The fast path loads the pointer with `std::memory_order_acquire`; if non-null it is returned immediately.
- On a null cache, a fresh `Logger` is resolved and installed with `compare_exchange_strong` (`acq_rel` on success, `acquire` on failure). If two threads race, both resolve the same named logger from `LogManager`, and only the first store wins; the loser harmlessly discards its (identical) result. The final value is loaded with `acquire` ordering before returning.

This guarantees that all callers observe a consistent, correctly-published `Logger` pointer without a mutex.

## Inter-Class Interactions

- Drives the `logger()` member generated by `LOG4QT_DECLARE_QCLASS_LOGGER` (declared in `logger.h`).
- Delegates name-to-logger resolution to `LogManager::logger(const QString &)`.
- The returned `Logger` is then used for all logging calls within the host class.

## Usage Example

```cpp
// Typically you do not use ClassLogger directly; the macro wires it up:
class Worker : public QObject
{
    Q_OBJECT
    LOG4QT_DECLARE_QCLASS_LOGGER  // adds: mutable ClassLogger + Logger *logger() const
public:
    void run()
    {
        logger()->info(QStringLiteral("Worker running"));
    }
};

// Equivalent manual use:
class Manual
{
    mutable Log4Qt::ClassLogger mClassLogger;
public:
    Log4Qt::Logger *logger() const { return mClassLogger.logger(/* QObject* */ nullptr); }
};
```
